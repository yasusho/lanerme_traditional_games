# 最終バランス詳細分析レポート v2
日付: 2026-01-05
対象: バグ修正後の最新シミュレーション (10,000ゲーム)

## 1. 概要
ゲーム進行にかかわる重大なバグ（ラウンドトークン枯渇時の停止、移動0処理、手番スキップ）を修正した後の環境での分析結果です。
ゲームが「設計通りに完全に動作した」初めてのデータであり、以前のレポートよりも信頼性が高いものです。

## 2. 定量的分析の更新 (Quantitative Analysis Update)

### 2.1 座席順の有利不利（新たな発見）
旧レポートでは「公平」とされていましたが、完全なゲームサイクルにおいては**明確な「後手番有利」**の傾向が現れました。

| 座席順 | 勝率 (4人戦) | 変動 |
| :--- | :--- | :--- |
| **Seat 1 (Start)** | **24.9%** | ▼ 平均的 |
| **Seat 2** | **26.7%** | △ やや有利 |
| **Seat 3** | **28.8%** | △ 有利 |
| **Seat 4 (Last)** | **32.6%** | **▲ 非常に有利** |

*   **要因分析**: 
    1. **ゲームの完走**: バグ修正によりゲームが必ず最終ラウンドまで続くようになったため、序盤のリソース不足を乗り越えて後半に爆発するプレイヤー（後手番など）が追いつく機会が増えました。
    2. **相乗り機会の最大化**: 後手番のプレイヤーは、他プレイヤー全員が動いた後に自分の位置を決められます。また、「移動0」修正により「その場に留まる（＝他プレイヤーと同じマスに居続ける）」ことが戦略的に正しく機能し始め、相乗り（Ride）による移動コスト削減の恩恵を最も受けやすい立場にあると推測されます。

### 2.2 戦略バランスの改善
バグ修正により、全てのAIロジックが意図通りに機能した結果、戦略間の格差は以前よりも縮まりました。

| 戦略 | 勝率 | 前回比 | 解説 |
| :--- | :--- | :--- | :--- |
| **Balanced** | **30.7%** | +4.4% | **最強**。攻守のバランスが完璧に機能。 |
| **Naive** | **28.4%** | +2.3% | 単純思考だが、余計なことをしない強さがある。 |
| **Rusher** | **28.2%** | +2.7% | 依然として強力な選択肢。 |
| **Hoarder** | **25.8%** | +3.7% | **大幅改善**。ゲームが最後まで続くようになり、溜め込んだ資源を吐き出す時間が生まれた。 |

### 2.3 カード評価（Tier）の再確認
「アイルの道」などのエンドカードの強さは変わりませんが、ゲームが長引くようになったことで、中盤向けカードの重要性が増しています。

*   **Tier S (変わらず)**: アイルの道 (57.7%)
*   **Tier A**: 良き文化 (49.9%), 筆兵無傾 (47.9%)
*   **注目株**: **機械油の力 (35.6%)** - 勝率3割中盤を維持。中盤のエンジンとして必須級。
*   **不遇枠**: ナナラ港 (22.0%) - 港の恩恵を受ける前にゲーム展開についていけないケースが多い模様。

## 3. 結論
### ゲームとしての完成度
バグ修正を経て、**「最後まで逆転の目がある（後手がまくれる）レースゲーム」**として完成しました。
Hoarder（貯蓄型）が息を吹き返したことは、多様なプレイスタイルを許容する良い兆候です。

### 今後の調整案（もし行うなら）
*   **Start Playerへの補正**: Seat 1の勝率が一番低いため、初期資源を1つ（F/M/Kのいずれか）多く持たせてスタートするなどのハンデを与えても良いかもしれません。
*   **Seat 4への抑制**: 初期位置を調整する、あるいは初期リソースを減らすなどの微調整が考えられますが、32%という勝率は「圧倒的」とまでは言えないため、現状維持でも許容範囲です（実力差の方が大きく出るため）。

**推奨アクション**: 現時点でルールの変更は行わず、この「完成版」としてリリースすることを推奨します。
