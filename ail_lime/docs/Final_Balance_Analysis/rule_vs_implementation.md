# ルール vs 実装 比較レポート

## ✅ 一致している項目

| ルール | 実装 | 状態 |
| :--- | :--- | :--- |
| **周回トークン**: プレイヤー数 x 3 | `this.roundTokens = playerCount * 3;` | ✅ 一致 |
| **相乗り**: 上に乗っているコマを運ぶ | `getPassengers()` + `updateNodeStacks()` | ✅ 一致 |
| **相乗りボーナス**: 運ばれた人もマス報酬を得る | `passengers.forEach(p => { p.resources[...] })` | ✅ 一致 |
| **ゲーム終了**: トークンがなくなった**ラウンド終了時** | `gameEndTriggered` フラグで管理 | ✅ 一致 |
| **周回ボーナス**: 1=1, 2=3, 3=6, 4=10, 5+=3/枚 | `calculateVP()` の周回ボーナス計算 | ✅ 一致 |
| **手札補充**: 3枚まで (draw_extra で上限増) | `runRound` 補充フェーズ | ✅ 一致 |
| **スタートプレイヤーローテーション**: 左隣へ渡す + 1枚ドロー | `startPlayerIndex++` + `drawCards(..., 1)` | ✅ 一致 |
| **建設連鎖**: アイコンがあれば続けて建設可能 | `chain_build` プロパティ + ループ処理 | ✅ 一致 |
| **変換**: 1ターン1回 | `card.usedThisTurn` フラグ | ✅ 一致 |
