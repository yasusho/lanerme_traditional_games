# 同名カードの重複建設制限の修正確認 (Walkthrough)

## 修正内容
プレイヤーが同じ名前（同じID）のカードを複数枚建設できないように制限を追加しました。

### 1. 建設可否判定の強化
- `Game` クラスに `canBuild(player, card)` メソッドを新設しました。
- このメソッドは以下の2点をチェックします：
  1. **重複チェック**: プレイヤーの建設済みカード（`construction`）の中に、現在選択しているカードと同じ ID のカードが含まれていないか。
  2. **コストチェック**: 既存の `checkCost` を呼び出し、リソースが足りているか。

### 2. UIの改善
- 建設アクション（Action B）を表示する際、`canBuild` メソッドの結果に基づいてボタンを制御するようにしました。
- 既に同じカードを建設済みの場合：
  - ボタンのテキストを 「Action B: Build」 から 「**Action B: Already Built**」 に変更。
  - ボタンを **非活性（disabled）** に設定。
  - ツールチップにも 「Already Built」 と表示されるようにしました。

### 3. AIの制御
- AIも同様に `canBuild` メソッドを使用して建設を判断するように修正しました。これにより、AIが不必要に重複したカードを建設しようとすることがなくなりました。

## 動作確認結果
- ブラウザ上のシミュレーターで、既に「機械油の力」を建設している状態で、手札から2枚目の「機械油の力」を選択した際、建設ボタンが「Already Built」となりクリックできないことを確認しました（スクリーンショット `whole_page_simulator_1767026091027.png` で確認済み）。
- リソースが足りない場合は従来どおり「Insufficient Resources」として非活性になります。
