# タスク：UIの利便性向上

UIをより使いやすく、視認性の高いものに改善します。

## 1. 視覚的フィードバックの強化
- [ ] リソース表示をテキストからアイコン（トークン）に変更
- [ ] 現在のプレイヤーをより明確に強調（サイドバー、ボトムパネル）
- [ ] フェーズ遷移の視認性向上（ヘッダーのデザイン改善）

## 2. ログシステムの改善
- [ ] ログの表示領域を調整（自動スクロール、メッセージの種類による色分け）
- [ ] ログをサイドバーから独立させるか、より使いやすく配置

## 3. カード操作の改善
- [ ] ホバー時にカードの詳細（拡大表示）を出す機能の検討
- [ ] 手札の選択状態をより分かりやすく

## 4. マップのインタラクション改善
- [ ] 移動可能なノードを強調（アニメーション追加）
- [ ] 他のプレイヤーの位置を分かりやすく表示

## 5. 全体的な磨き上げ
- [ ] フォントの一貫性と読みやすさの向上
- [ ] モダンな配色とガラスモーフィズムの導入
