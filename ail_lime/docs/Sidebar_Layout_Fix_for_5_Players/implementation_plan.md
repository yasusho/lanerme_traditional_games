# 5人プレイ時のUIレイアウト修正計画

5人プレイ時にプレイヤー情報がサイドバーを占有し、プレイログが下に隠れてしまう問題を修正します。

## 修正内容

### 1. CSSの修正 (`style.css`)

サイドバー内の管理方法を変更します。

- `.sidebar`: `overflow-y: auto` を削除し、コンテナとしての固定表示を維持します。
- `#opponents-area`: `flex: 1` を設定し、`overflow-y: auto` を追加することで、プレイヤーが多い場合にこのエリア内だけでスクロールするようにします。
- `#log-area`: サイドバー構成要素として、下部に固定（押し下げ）されるようにし、高さを確保します。

### 2. レイアウトの微調整

- 全体的な高さ制限の確認。
- プレイヤーボードのパディングや間隔が大きすぎる場合は少し詰めて、より多くの情報を一度に表示できるようにします。

## 検証計画

- **手動確認**:
    - 5人プレイで開始し、サイドバーに4人の対戦相手が表示されている状態で、最下部のログエリアが正しく表示されているか確認します。
    - ログが増えた際に、ログエリア内でのスクロールが機能するか確認します。
    - 対戦相手が多い場合に、プレイヤーリスト部分がスクロール可能になっているか確認します。
