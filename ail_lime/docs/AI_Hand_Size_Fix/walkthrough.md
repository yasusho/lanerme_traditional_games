# AIの手札枚数異常（無限増加）の修正完了 (Walkthrough)

AIプレイヤーの手札が毎ラウンド増え続け、意図せず大量の手札を持ってしまう不具合を修正しました。

## 修正内容

### `game.js` の修正

- **`executeAITurn` メソッドの修正**:
    AIが「建築」ではなく「移動」アクションを選択した際、使用したカードを消費する処理が欠落していました。以下の処理を追加することで、人間プレイヤーと同様にカードが正しく管理されるようにしました。
    - 使用したカードを `discardPile` (捨て札) に追加。
    - `removeCardFromHand` を呼び出し、プレイヤーの手札からカードを削除。
    - `player.selectedCard` を `null` にリセット。

これにより、補充フェイズ (`startReplenishPhase`) で「手札が3枚（または4枚）になるまで補充する」ロジックが正しく機能し、手札が溢れることがなくなりました。

## 検証結果

- **シミュレーションモードでの動作**:
    - AIプレイヤーの手札が、補充フェイズ後に正しく3枚（親の場合は4枚）に保たれることを確認しました。
    - ログに「Player X が ... を公開」と表示されたタイミングで、UI上の手札表示からカードが1枚減ることを確認しました。
- **捨て札のリシャッフル**:
    - 山札が尽きた際、移動に使用されたカードを含む捨て札が正しくリシャッフルされ、山札として再利用されることを確認しました。
