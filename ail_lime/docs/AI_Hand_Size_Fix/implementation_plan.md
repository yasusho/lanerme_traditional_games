# AIの手札枚数異常（移動時のカード消費漏れ）の修正計画

AIプレイヤーが移動アクションを選択した際、使用したカードを手札から削除せず、かつ捨て札にも送っていないため、手札が減らずに補充フェイズで増え続けてしまう問題を修正します。

## 修正内容

### `game.js` の修正

#### [MODIFY] `executeAITurn`
AIが「建築」ではなく「移動」を選択した場合（`else` ブロック）の冒頭に、以下の処理を追加しました。
- `this.discardPile.push(card)`
- `this.removeCardFromHand(player, card)`
- `player.selectedCard = null`

## 検証プラン

- **シミュレーションモードでの確認**:
    - AIの手札が常に上限（通常時3枚、親の時4枚）付近で維持され、時間とともに増え続けないことを確認済みです。
- **捨て札の確認**:
    - 山札が空になった際、捨て札が正しくリシャッフルされることを確認済みです。
