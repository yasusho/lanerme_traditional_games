## 1. ゲームの目的

マップを周回しながらカードを建設し、**最も多くの勝利点（VP）**を獲得したプレイヤーの勝利です。

---

## 2. 準備

1. マップを中央に置く
2. **周回トークン**を**人数×3枚**用意
3. 全員のコマを「01. マカティ」に置く
4. 各自に**カード3枚**配る
5. スタートプレイヤーを決める

---

## 3. ゲームの進め方

### 3.1 ラウンドの流れ

```
┌────────────────────────────────────────────────────┐
│  ① 計画     →    ② 実行    →     ③ 補充        │
│  (全員同時)      (順番に)       (全員同時)        │
│                                                    │
│  カード1枚      「進む」か      手札3枚まで       │
│  裏向きで出す    「建てる」     補充              │
└────────────────────────────────────────────────────┘
```

### 3.2 アクションA：進む

カードを捨て、移動数だけ進みます。

| 順番 | やること |
| :--- | :--- |
| 1 | 移動する（0〜3歩） |
| 2 | 周回チェック（10→01を通過したらトークン獲得） |
| 3 | 資源を得る（カード効果 + 到着マス） |

**相乗り**: 自分の上にいるプレイヤーも一緒に移動します。
運ばれた人は**到着マスの資源のみ**獲得できます。

### 3.3 アクションB：建てる

カードのコストを払い、手元に置きます（移動しない）。

- **お金(W)** はどの資源の代わりにも使える
- **建設連鎖**: アイコンがあれば続けて建設可能

### 3.4 補充フェイズ

1. 手札が**3枚**になるまで引く（「ドロー追加」効果で上限増）
2. スタートプレイヤーが左隣へ移動

### 3.5 ゲーム終了

**周回トークンが0枚**になったら、**そのラウンド終了後**にゲーム終了。

## 7. 詳細ルール

### 相乗り
- 自分の**上**にいる人を全員運ぶ
- 運ばれた人は**マス資源のみ**獲得
- 周回トークン・カード効果資源は**もらえない**

### 資源上限
- 最大 **10個**。超過分は銀行へ戻す

### お金(W)の使い方
- **支払い時のみ**他資源として使用可
- 「K+1」の効果でWは代用できない

### 移動数0
- 「進む」を選んでも動かない（現在地の資源は得られる）

### 建設不可の場合
- コストが払えなければ **必ず「進む」を選ぶ**
