# 初期配置の駒の重複回避および相乗り禁止の実装計画

ゲーム開始時にプレイヤーの駒がNode 01に密集し、重なって表示される問題、および最初の移動で全員を連れて行ってしまう（相乗りが発生する）問題を解消します。

## ユーザーレビューが必要な項目
> [!IMPORTANT]
> ゲーム開始時、プレイヤーは同じノード（Node 01）にいますが、**「スタック（積み重ね）」が形成されていない状態**として扱います。これにより、最初の移動では他のプレイヤーを運びません。一度移動して他のプレイヤーがいるノードに止まった時点でスタックが形成され、以降は通常通り相乗りが発生します。

## 提案される変更

### `simulator` コンポーネント

#### [MODIFY] [game.js](file:///c:/Users/yasus/Documents/lanerme_traditional_games/ail_lime/simulator/game.js)
1.  **初期化ロジックの変更**:
    - `_initGameLogic` 内で、プレイヤーを `nodeStacks[1]` に追加する処理を削除します。
    - プレイヤーは `location: 1` ですが、スタック外の状態からスタートします。
2.  **相乗りロジックの改善**:
    - `getPassengers` が、プレイヤーがスタックに含まれていない場合（`indexOf === -1`）に空配列を返すことを確認（現状でもそうなっています）。
3.  **移動ロジックのガード**:
    - `updateNodeStacks` にて、移動元ノードのスタックにプレイヤーがいない場合でも正常に動作するように修正します。
4.  **描画ロジックの強化**:
    - `renderMap` 内で、プレイヤーがスタックにいない場合の座標計算を追加します。
    - ノードを中心とした一定の半径上に、プレイヤーIDに基づいて分散配置します。

### `simulator` スタイル調整
- 必要に応じて `player-token` のスタイルを微調整します。

## 検証計画

### オートメーションテスト
1. ブラウザツールで `game.nodeStacks[1]` が初期状態で空であることを確認します。
2. 最初のプレイヤーが移動した際、他のプレイヤーの `location` が更新されないことを確認します。

### 手動確認
1. ゲームを開始時、5つの駒がNode 01の周りに円状または並んで表示され、重なっていないことを確認。
2. 最初のプレイヤーが移動した際、その駒だけが動き、他の駒がその場に残る（相乗りが発生しない）ことを確認。
