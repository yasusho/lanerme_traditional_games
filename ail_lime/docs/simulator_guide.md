# AIL LIME シミュレーター 操作ガイド

## 起動方法

`simulator/index.html` をブラウザで開いてください。

---

## 画面構成

| エリア | 説明 |
| :--- | :--- |
| **マップ** | 中央に表示。クリックで移動先を選択 |
| **手札** | 画面下部。カードをクリックして選択 |
| **建設エリア** | 各プレイヤーの建設済みカードを表示 |
| **資源表示** | 各プレイヤーの保有資源を表示 |
| **ログ** | ゲームの進行状況を表示 |

---

## 操作方法

### 計画フェイズ
1. 手札からカードを **クリック** して選択
2. 他のプレイヤーが選び終わるのを待つ（対人プレイ時）

### 実行フェイズ

#### 「進む」を選ぶ場合
1. **「進む」ボタン** をクリック
2. マップ上の **移動可能なマス** をクリックして移動先を選択
3. 移動先は黄色くハイライトされます

#### 「建てる」を選ぶ場合
1. **「建てる」ボタン** をクリック
2. コストが自動で支払われます
3. 建設連鎖がある場合、追加で建設するカードを選択

#### 変換を使う場合
1. 変換可能な建物がある場合、 **「変換」ボタン** が表示されます
2. クリックして資源を変換

### 補充フェイズ
- 自動で手札が補充されます
- スタートプレイヤーが自動で移動します

---

## ショートカット

| キー | 機能 |
| :--- | :--- |
| `M` | 「進む」を選択 |
| `B` | 「建てる」を選択 |
| `C` | 変換を実行 |

---

## 注意事項

- **建てられない場合**: コスト不足の場合、「建てる」ボタンは無効化されます
- **移動先がない場合**: 移動数0のカードでも「進む」は選択可能です（その場で資源獲得）
- **AI対戦**: プレイヤー人数設定でAIを追加できます
