# プレイヤー人数別傾向分析レポート

## 1. 概要
2人～5人プレイまでの全データを横断的に分析し、プレイ人数が増えることによるゲーム性の変化（トレンド）を検証しました。

## 2. 分析結果

### A. ゲームスピード（平均終了ラウンド）
人数が増えるほど、わずかにゲーム終了が早まる傾向があります。

| 人数 | 平均ラウンド |
| :--- | :--- |
| 2人 | 20.97 |
| 3人 | 21.13 |
| 4人 | 20.45 |
| 5人 | **19.76** (最速) |

**考察:**
プレイヤー数が増えることでフィールド上のリソース（特に勝利点に直結するカードや資源）の奪い合いが激化し、誰かが突出してゴール（特定VP到達や山札切れ要件）に触れるまでの期間が短縮されていると考えられます。「ダラダラと長引かない」良い傾向です。

### B. 先行有利のバイアス (Play 1 Bias)
先行（Player 1）の有利度は、人数に関わらず一貫して存在します。

| 人数 | P1勝率 | 期待値 | **バイアス (上乗せ分)** |
| :--- | :--- | :--- | :--- |
| 2人 | 54.10% | 50.00% | **+4.10%** |
| 3人 | 36.41% | 33.33% | **+3.08%** |
| 4人 | 28.57% | 25.00% | **+3.57%** |
| 5人 | 24.25% | 20.00% | **+4.25%** |

**考察:**
どの人数でも「期待値 +3～4%」程度の上乗せがあります。これは「先行がリソースを1手早く取れる」ことによる構造的な有利であり、人数によって悪化も緩和もしていません。許容範囲内のバイアスと言えます。

### C. 戦略の有効性推移 (Strategy Effectiveness)
人数が増えるほど、「下手な戦略（Naive）」への罰則が厳しくなります。

| 人数 | Balanced | Hoarder | Rusher | Naive |
| :--- | :--- | :--- | :--- | :--- |
| 2人 | **54.4%** | 49.0% | 48.4% | 48.2% |
| 3人 | **38.0%** | 32.5% | 30.4% | 32.5% |
| 4人 | **29.9%** | 25.0% | 22.7% | 22.3% |
| 5人 | **24.2%** | 20.6% | 18.5% | *16.6% (急落)* |

**考察:**
*   **Naiveの没落:** 2人戦ではBalancedと大差ありませんが（差6%）、5人戦では致命的な差（差7.6%）がつきます。5人戦ではリソース管理のミスが命取りになることを示しています。
*   **Balancedの安定感:** どの人数帯でも常にトップであり、スケーラビリティのある優れたアルゴリズムであることが証明されました。

## 3. 結論
*   **多人数プレイほど実力差が出る:**
    5人プレイは運要素も増えますが、それ以上に「ミスの許されなさ」が顕著です。Balanced AIの強さが最も際立つのは多人数戦です。
*   **ゲームスピードの安定:**
    人数が増えてもプレイ時間が間延びせず、むしろテンポアップするのは良いデザインです。
