# ゲーム統計機能の実装完了 (Walkthrough)

ゲームバランスの分析を容易にするため、シミュレーターに詳細な統計データ収集およびエクスポート機能を実装しました。

## 実施した変更内容

### 1. 統計データ構造の拡張 (`game.js`)
`initStats` メソッドを更新し、以下の詳細なデータを追跡できるようにしました。
- **資源獲得ソースの分類**: 移動、産出、移動ボーナスのそれぞれでどの資源をどれだけ得たか。
- **ワイルド資源の利用内訳**: `W` (Wild) が `F`, `M`, `K` のどの代わりとして何回消費されたか。
- **VPソースの分類**: カードの固定VP、条件付き変動VP、周回トークンによるVPの合算値。
- **時系列スナップショット**: 各ラウンド開始時の全プレイヤーの状態（資源、VP、建設カード数）を保持。

### 2. ロジックの組み込み
- `deductResources`: 資源支払い時に、通常資源とワイルド資源の消費を個別に記録するよう強化。
- `calculateVP`: VP計算時に、統計記録用のフラグを追加し、カードごとの貢献度を累計。
- `recordRoundStats`: ラウンドごとの状態を `roundHistory` に保存する新メソッドの実装。

### 3. UIとエクスポート機能
- `endGame`: ゲーム終了画面にUIを統合。
- **統計データ表示**: トップ5の貢献カードや、資源フローの概要を結果画面のスクロール可能なエリアに表示。
- **JSONエクスポート**: ボタン一つで、収集した全統計データをJSONファイルとしてダウンロード可能。

---
> [!NOTE]
> 統計データは `this.stats.roundHistory` に配列として蓄積されているため、将来的に折れ線グラフなどで資源推移を可視化することも可能です。
