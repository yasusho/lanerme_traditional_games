# 相乗りルールの修正確認 (Walkthrough)

## 修正内容
シミュレーターにおける「相乗り（ride-sharing）」ルールを、本来のルール仕様である「スタック構造」に基づいて修正しました。

### 1. スタック管理の導入
- 各マスに `nodeStacks` という概念を導入しました。
- プレイヤーがマスに到着すると、そのマスのスタックの「一番上」に追加されます。
- `Game` クラスに `nodeStacks` データを保持し、移動ごとに更新するようにしました。

### 2. 相乗りロジックの適正化
- **修正前**: 同じマスにいる全プレイヤーを一律で運んでいました（磁石のような挙動）。
- **修正後**: 自分が移動する際、自分より「上」に重なっているプレイヤーのみを運ぶように変更しました。
- 自分より下にいるプレイヤーは、その場に残ります。

### 3. 移動後の相対順序の維持
- 運ばれたプレイヤー（パッセンジャー）は、移動先のマスでも移動させたプレイヤーの上に重なった状態を維持します。
- これにより、複数人が同時に移動しても、その後の手番で正しく相乗りが発生します。

### 4. 視覚的表示の改善
- `renderMap` を更新し、スタックの順序に応じて駒を少しずつずらして表示するようにしました。
- ツールチップに「Stack Pos」を表示し、誰が誰の上にいるかをデバッグしやすくしました。

## 動作確認結果
- 5人全員が Node 1 にいる状態から Player 1 (Bottom) が移動した際、全員が Node 2 へ運ばれることを確認しました。
- その後、Node 2 で Player 4 が移動した際、Player 4 より上にいた Player 5 だけが運ばれ、下にいた Player 1, 2, 3 は Node 2 に残ることを確認しました。
- プレイヤーがバラバラに動けるようになり、ルール通りの戦略性が確保されました。
