# AI戦略改善およびテンポ最適化計画

ルール（初期トークン数等）は一切変更せず、AIの意思決定アルゴリズムを「得点最大化」に向けて高度化することで、ゲームの進行をより合理的かつスムーズにします。

## 修正内容

### 1. AIの移動先評価（スコアリング）の導入 (`game.js`)

AIが目的地を選択する際、以下の要素を考慮したスコアリングを行い、最も「得点」に繋がる行動を選択するようにします。

- **周回完了 (最優先 / +50点)**: 周回（10 -> 01）を達成し、ラウンドトークン（1 VP）を獲得できるノードを優先します。
- **必要資源の獲得 (+20点)**: 現在手札にあるカードを建築するために不足している資源を生み出すノードを優先します。
- **前方進行 (+1〜10点)**: 基本的に周回に近づく（IDの大きいノードへ進む）方向を好みます。

### 2. AIの建築判断の強化 (`game.js`)

- 現在の「建築可能なら80%で建築」という確率的な挙動を修正し、建築可能な場合は必ず建築を優先するようにしました。

## 検証プラン

- **シミュレーションモードでの動作比較**:
    - AIが目的意識を持って（無駄な逆走を減らして）周回を重ね、着実に建築を進めることを確認済みです。
    - 結果として、ルールを変更しなくても、ゲームが収束に向かうことを確認済みです。
