# AIL LIME シミュレーター: ルール vs 実装 比較表

## 概要
このドキュメントは `rule.md` に記載されたゲームルールと、現在の `game.js` / `cards.js` の実装状況を比較したものです。

---

## 1. ゲーム準備

| ルール | 実装状況 | 備考 |
|--------|----------|------|
| プレイヤー人数: 3〜5人 | ✅ 実装済み | セットアップ画面で2〜5人を選択可能 |
| 周回トークン: 人数 × 3個 | ✅ 実装済み | `_initGameLogic` で `playerCount * 3` を設定 |
| 全員「01. マカティ」からスタート | ✅ 実装済み | `location: 1` で初期化 |
| 初期手札: 3枚 | ✅ 実装済み | `drawCards(p, 3)` |
| コマを重ねて置かない | ✅ 実装済み | `nodeStacks` でスタック管理 |

## 2. 計画フェイズ

| ルール | 実装状況 | 備考 |
|--------|----------|------|

| 残った手札は保持 | ✅ 実装済み | `selectedCard` を設定するのみで手札から除去しない（実行時に除去） |

## 3. 実行フェイズ

### 【アクションA：進む】

| ルール | 実装状況 | 備考 |
|--------|----------|------|
| カードを捨て札にする | ✅ 実装済み | `discardPile.push(card)` |
| 移動数だけ進む (0〜3) | ✅ 実装済み | `getReachableNodes` + `finishMove` |
| 相乗り: 上のコマを全員運ぶ | ✅ 実装済み | `getPassengers` + `updateNodeStacks` |
| 周回トークン獲得 (10→01通過時) | ✅ 実装済み | `checkPathForLoop` |
| **カード報酬**: 移動時獲得資源 | ✅ 実装済み | `finishMove` で `move_resource` を処理 |
| **マス報酬**: 止まったマスの資源 | ✅ 実装済み | `finishMove` で `node.resource` を処理 |
| **産出**: 建設済みカードの産出効果 | ✅ 実装済み | `gainTriggeredProduction` でマス資源に応じて発動 |
| **相乗りボーナス**: 運ばれた人はマス報酬のみ | ✅ 実装済み | `finishMove` で passengers に `node.resource` のみ付与 |

### 【アクションB：建てる】

| ルール | 実装状況 | 備考 |
|--------|----------|------|
| コスト支払い | ✅ 実装済み | `showPaymentModal` + `deductResources` |
| カードを建設エリアに置く | ✅ 実装済み | `player.construction.push(card)` |
| コマは動かない | ✅ 実装済み | `location` 変更なし |
| マス報酬は得られない | ✅ 実装済み | `finishMove` を呼ばない |
| 建設連鎖 | ✅ 実装済み | `chain_build` + `showChainBuildActions` |

### 【フリーアクション：変換】

| ルール | 実装状況 | 備考 |
