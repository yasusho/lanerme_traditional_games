# 建設連鎖と重複建設の仕様修正：実装計画

## 現状の課題
- 重複建設の制限を導入したが、ユーザーより「重複自体は許容されるが、1手番で複数建つことが問題」との指摘があった。
- 「建設連鎖」のルール（特定のカードを建てた後、続けて別のカードを建てられる）が未実装であり、ユーザーが混乱している可能性がある。
- 現状、1手番で1アクション（移動か建設）が原則だが、建設連鎖がある場合は例外となる。

## 修正方針
1. **重複建設の制限を緩和**:
   - `canBuild` における「同名カードの重複チェック」を削除し、同じカードを複数回建設することを許可する（コストが払える限り）。
2. **建設連鎖の実装**:
   - 建設アクション実行後、そのカードに `chain_build` アイコンがある場合、手番を終了せずに「追加の建設」を可能にする。
   - 人間プレイヤーの場合、追加のカードを選択できる専用のUIを表示する。
   - AIプレイヤーの場合、リソースが許せば追加で建設を行う。
3. **ターンの管理**:
   - 通常の建設後は `endTurn()` を呼ぶが、連鎖が残っている場合は呼ばないように制御する。

## 実装内容
- `executeBuild(player, card, chainRemaining = 0)` に引数を追加し、連鎖回数を追跡する。
- `executeBuild` 内で `card.chain_build` から連鎖回数を取得し、`showChainBuildActions` を呼び出す。
- `showChainBuildActions(player, chainRemaining)`:
  - 手札の中から建設可能なカードをリストアップし、選択肢として表示する。
  - 「連鎖を終了する」ボタンも用意する。
- AIの `executeAITurn` も連鎖に対応させる。

## 期待される効果
- ルールブック通りの「建設連鎖」が体験できるようになる。
- 1手番で許可なく複数の建物が建つ（あるいは建たない）といった不自然な挙動が解消される。
- 重複建設ができるようになり、リソース産出特化などの戦略が可能になる。
