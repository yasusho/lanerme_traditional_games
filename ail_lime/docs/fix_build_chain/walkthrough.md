# 建設連鎖機能の実装と重複建設の許可 (Walkthrough)

## 修正内容
ユーザーのフィードバックに基づき、建設ルールの適正化と不足機能の実装を行いました。

### 1. 同名カードの重複建設を許可
- `canBuild` メソッドから重複チェックを削除しました。
- これにより、リソースさえあれば同じ建物を複数個建設できるようになりました（ルール通りの挙動）。

### 2. 建設連鎖 (Build Chain) の実装
- 建設連鎖アイコン（`chain_build` プロパティ）を持つカードを建設した際、手番を終了せずに追加の建設を行えるようにしました。
- **人間プレイヤーの場合**: 「Chain Build Phase」として、手札から建設可能なカードが一覧表示され、続けて建設できるようになります。「Finish Turn」ボタンで終了も可能です。
- **AIプレイヤーの場合**: リソースが許す限り、ランダムに手札から追加のカードを建設します。

### 3. 1手番内での建設回数の適正管理
- これまで「建設連鎖」が未実装だったため、1手番で1枚のみの建設でしたが、本来のルールでは連鎖によって複数枚建つのが正解です。
- ただし、連鎖アイコンがないカードを建てた場合は、即座に次のプレイヤーの手番へ移行するように確実な `endTurn()` 呼び出しを維持しています。

## 動作確認
- ブラウザシミュレーターにて、連鎖アイコンを持つカード（例：「投資」ID: 13）を建設した際、追加の建設UIが表示されることを確認しました。
- 同じカードを複数枚並べて建設できることを確認しました。
