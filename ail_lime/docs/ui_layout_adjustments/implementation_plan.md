# UI改善と初期配置の調整 計画書

## 目的
ユーザーからのフィードバックに基づき、以下のUIおよびロジックの改善を行います。
1. 初期設定時にトークンが重なって（「相乗り」状態で）表示されないようにし、視覚的な分離を明確にします。
2. プレイスペース（Tableau）をより大きく、見やすくします。
3. プレイヤーゾーン右側の重複しているRT（ラウンドトークン）表示を削除します。
4. 横幅をフルに活用し、左右の不要な空白を削減します。

## 提案される変更

### 1. 初期配置の調整（視覚的分離の強化）
- `game.js` の初期化後のトークン描画において、スタック（重なり）状態にないトークンの配置間隔を広げ、より明確に個別であることを示します。

### 2. Tableauのサイズ拡大
- `style.css` において、`.tableau` のベースサイズを拡大します。
- `.card-thumb`（Tableau内のカードプレビュー）のサイズを大きくし、視覚的な存在感を強めます。

### 3. RT表示の削除
- `game.js` の `updateUI` メソッドから、プレイヤーゾーン右側の個別のRT表示ブロックを削除します。
- プレイヤー情報内のリソースタグとしてのRT表示は維持し、情報の集約を図ります。

### 4. マップ表示の修正とサイドバーの拡大
- `style.css` において、サイドバー (`.sidebar`) の幅を `320px` から `450px`〜`500px` 程度に拡大します。
- `main-area` におけるマップとサイドバーの `flex` 比率を調整し、サイドバーに十分な情報量を、マップには適切な表示領域を割り当てます。
- マップ周辺の余白をさらに削り、サイドバーを広げた分をマップの「空の海」の部分で吸収するようにレイアウトを最適化します。
