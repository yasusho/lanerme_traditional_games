# 現行シミュレーター実装 ルールブック

## 1. ゲーム概要
- プレイ人数: 3〜5人
- ラウンドは **計画フェイズ → 実行フェイズ → 補充フェイズ** の順で進行
- 各プレイヤーは手札 3 枚（開始プレイヤーは 4 枚）を保持

## 2. 資源生産
- **建築時** にカードに記載された `production` が即座に適用され、資源が 1 回だけ付与されます。
- `production_logic` が `variable` の場合、建築済みカードのカテゴリ数に応じて資源が付与されます（例: `culture` カードの数だけ `K` が得られる）。

## 3. コスト支払い
- カードの `cost` が足りない場合、**ワイルド資源 `W`** が不足分を自動的に補填します。
- `multi: "same3"` のカードは、3 種類の資源のいずれかが最大値で、`W` と合わせて 3 以上で支払可能です。

## 4. 相乗り（Ride‑Sharing）
- 移動時に自分のコマ上に他プレイヤーのコマがある場合、全員を同時に目的地へ運びます。
- 移動先のマスの資源は、**自分** と **乗せられたプレイヤー** の両方に付与されます（乗せられた側はマス報酬のみ）。

## 5. 周回判定
- 移動で **10 → 01** のルートを通過（または到達）すると **ラウンドトークン** が 1 つ獲得されます。
- `checkPathForLoop` が true のとき、`roundTokens--` とプレイヤーの `roundTokens++` が実行されます。

## 6. 得点計算（VP）
- **建築カード** の `vp_logic` が `static` の場合、カードに記載された VP をそのまま加算。
- `variable` の場合、建築済みカードのカテゴリ数に応じて VP を算出（例: `culture` カードの数）。
- **ラウンドトークン** によるボーナスは以下の累積式で計算されます。
  - 0 トークン: 0
  - 1 トークン: 1
  - 2 トークン: 3
  - 3 トークン: 6
  - 4 トークン: 10
  - 5 以上: `10 + (t - 4) * 3`

## 7. 手札上限と補充
- 補充フェイズで **手札が 3 枚になるまで** カードをドローします。
- スタートプレイヤーは補充フェイズで追加で 1 枚ドローし、最大 4 枚になります。
- 現在、カードの上限増加や変換アクションは実装されていません。

## 8. 未実装・差異
- ルールブックに記載されている **変換アクション**（例: `K2→W`）や **ドロー追加効果** は、現行シミュレーターではロジックが未実装です。
- 手札上限の増加や特殊効果は UI 表示のみで、実際のゲームロジックには反映されていません。
