# ゲームバランス分析レポート

10,000回のシミュレーション結果（2〜5人プレイ）に基づき、現在のゲームバランスの良い点と悪い点を分析しました。

## 📊 分析結果サマリー

| プレイ人数 | 平均ラウンド数 | 1番手勝率 | 最下番手勝率 | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| **2人** | 22.0 | **55.45%** | 44.55% | 先手がかなり有利 |
| **3人** | 21.7 | **39.00%** | 29.00% | (期待値 33.3%) 先手が有利 |
| **4人** | 21.5 | **31.32%** | 20.21% | (期待値 25.0%) 先手が圧倒的 |
| **5人** | 21.3 | **22.62%** | 16.57% | (期待値 20.0%) 席順差が顕著 |

## ✅ 良い点 (Good Points)

1.  **ゲーム展開の安定性 (Game Pacing)**
    *   プレイ人数に関わらず、ゲーム終了までのラウンド数が **21〜22ラウンド** で安定しています。
    *   標準偏差も約1.1と小さく、極端に長引くゲームや早期終了が少ないため、プレイ時間の予測が立てやすい設計です。

2.  **基本カードの有効性**
    *   「資源の採掘」や「法改正」といった基本カードが勝利デッキの多くに含まれており、基本アクションが腐らない健全なデザインです。

## ⚠️ 悪い点 (Bad Points)

1.  **深刻な先手番有利 (First-Player Advantage)**
    *   すべてのプレイ人数において、**手番が早いプレイヤーの勝率が明確に高い**傾向があります。
    *   特に2人対戦では55%対45%と大きな差があり、4人対戦でも1番手(31%)と4番手(20%)で1.5倍以上の勝率差が生じています。
    *   *推奨される対策*: 後手番プレイヤーへの初期資源ボーナスや、VP補正の検討が必要です。

2.  **カードパワーの格差 (Card Imbalance)**
    *   **強力すぎるカード**:
        *   `機械油の力` (勝率寄与度が高い): 多くの勝利デッキに含まれており、コスト対効果が高すぎる可能性があります。
        *   `アイル国民の力`: これも同様に非常に高い採用率と勝率を誇ります。
    *   **弱すぎるカード**:
        *   `アイル共和国憲法`、`良き文化`、`アイルの道`: これらは勝利デッキにほとんど含まれていません（10000回中数回〜数十回）。コストが重すぎるか、効果が限定的すぎる可能性があります。

### 🤖 AIの挙動に関する追記 (AI Logic Analysis)

ユーザーの指摘に基づき、AIロジックを確認しました。
*   **現状のAI**: 手札にあるカードのうち「**現時点で建設可能なもの**」を最優先（スコア+1000）で選択します。建設できない場合は、移動用カードとして消費します。
*   **問題点**: AIには「高コストカードのために資源を貯める」という思考ルーチンがありません。そのターンにたまたま資源が足りていない限り、高コストカード（コスト5-6）は即座に移動コストとして捨てられてしまいます。
*   **結論**: `アイル共和国憲法` などの使用率が極端に低いのは、カード自体の弱さ以上に、**AIが貯蓄行動を行わないため**である可能性が高いです。これを修正するには、AIに「目標カードのために資源を温存する」ロジックを追加する必要があります。

## 📝 改善提案

1.  **スタートプレイヤー補正の導入**: 後手番のプレイヤーに初期資源（K/M）を1〜2個追加配布する。
2.  **「機械油の力」のコスト調整**: コストを増やすか、効果をわずかに弱体化させる。
3.  **「憲法」「文化」系の強化**: 得点効率を見直すか、特殊効果（アクション追加など）を付与する。
